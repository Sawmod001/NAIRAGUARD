# NG-001 — Project Initialization

> Source: `NairaGuard_Scrum_Tickets.md` + `docs/15_SCRUM_BACKLOG.md` + `docs/14_PROJECT_STRUCTURE.md`

## Goal

Create the clean initial NairaGuard application foundation without product features.

## Scope

- Initialize Next.js application
- TypeScript (strict)
- App Router
- pnpm-ready project
- Basic lint / typecheck configuration
- Clean initial source structure consistent with architecture
- Only dependencies genuinely required for initialization
- Application starts locally (`pnpm dev` / `npm run dev`)

## Do NOT Implement

- Authentication (Clerk)
- Database models / Prisma
- AWS providers
- Demo Mode providers / scenarios wiring
- Dashboard features
- Final homepage design
- AI provider
- FX provider
- Future features (budgets, alerts, mobile, etc.)

## Acceptance Criteria

- [ ] Project boots locally (`next dev` serves a page without error)
- [ ] TypeScript is configured (strict)
- [ ] App Router is used (`src/app/layout.tsx` + `src/app/page.tsx`)
- [ ] Basic lint / typecheck exists (`next lint`, `tsc --noEmit`)
- [ ] Structure follows `docs/14_PROJECT_STRUCTURE.md` — only what NG-001 needs
- [ ] No unnecessary future scope / dependencies
- [ ] No secrets committed (`.env.example` only, `.env*` gitignored)
- [ ] `pnpm` ready (or npm with note)

## Validation (sensible foundation only)

Use sensible foundation checks such as install / build / start as appropriate, typecheck, and lint if configured.
Do NOT run unrelated large test suites.

```bash
pnpm install        # or npm install
pnpm lint           # or npm run lint
pnpm typecheck      # or npx tsc --noEmit
pnpm build          # or npm run build
pnpm dev            # manual smoke check
```

## Stop

After NG-001, stop. Do not continue to NG-002.

Report:
- files changed
- what was implemented
- validation actually performed
- limitations or unresolved issues

Then COMMIT.

```
git remote add origin https://github.com/Sawmod001/NAIRAGUARD.git
git branch -M main
git push -u origin main
```
