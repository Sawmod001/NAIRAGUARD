# UI/UX Direction

## Brand

Primary:
- Black
- White
- Orange

The product should feel:
- technical
- premium
- confident
- infrastructure-focused
- Nigerian-market aware without becoming visually stereotypical

## Homepage

This is the most creative part of the product.

The homepage may use:
- GSAP
- React Three Fiber / Three.js where justified
- Framer Motion
- gradients
- animated data visualizations
- scroll-driven transitions
- kinetic typography
- subtle grid/cloud infrastructure motifs

Do not use effects merely because they are possible.

Every animation should support:
- understanding
- product identity
- hierarchy
- perceived quality

## Homepage visual rule

Do not copy the standard SaaS formula:

Hero → three cards → logo strip → three cards → pricing.

Create a product narrative.

Suggested narrative:

1. Dollar-denominated cloud problem
2. Naira exposure
3. Invisible waste
4. NairaGuard sees the cloud bill
5. NairaGuard finds opportunities
6. Savings translated into Naira
7. Recommendation evidence
8. Demo CTA
9. Trust/technical architecture
10. Final CTA

## Dashboard

Dashboard is intentionally less experimental.

Priority:
1. readability
2. hierarchy
3. financial accuracy
4. speed
5. actionability

## Visual system

Define tokens before building pages:
- background
- foreground
- muted text
- border
- accent orange
- success
- warning
- destructive
- chart palette
- spacing scale
- radius scale
- shadows
- typography scale

## Avoid

- excessive glassmorphism
- excessive gradients
- huge text everywhere
- unreadable charts
- animation on every element
- fake “terminal” UI without purpose
- decorative AWS logos everywhere
